## Featured Project

### WebSentinel

WebSentinel is a Python-based web security scanner designed for
educational and defensive security testing.

Main features:

- HTTP security header analysis
- Technology detection
- Low-impact SQL injection heuristics
- Common directory discovery
- Full scan mode
- Report generation
- Spanish / English interface

Repository:
